# 第三方组件

| 组件 | 用途 | 许可 |
| --- | --- | --- |
| [python-pptx](https://github.com/scanny/python-pptx) | 读取 PPTX 做文字检查、读取 PPT 材料 | MIT |
| [pypdf](https://github.com/py-pdf/pypdf) | 读取 PDF 材料 | BSD-3-Clause |
| [python-docx](https://github.com/python-openxml/python-docx) | 读取 Word 材料 | MIT |
| [openpyxl](https://foss.heptapod.net/openpyxl/openpyxl) | 读取 Excel 材料 | MIT |

以上组件通过 pip 安装，不随插件分发。排版引擎和它的组件在 aham-design 插件的 aham-ppt 技能里。
